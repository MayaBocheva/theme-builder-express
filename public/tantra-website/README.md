# Tantra Healing Website

A beautiful, responsive website for a Tantra healing practitioner.

## Files Included

- `index.html` - Main HTML file with all page content
- `style.css` - Complete CSS styling with responsive design
- `script.js` - JavaScript for FAQ accordion and mobile menu

## Features

- Fully responsive design (mobile, tablet, desktop)
- FAQ accordion functionality
- Smooth scroll navigation
- Mobile hamburger menu
- Modern, clean aesthetic with soft, calming colors

## How to Use

1. Download all files
2. Add your own images to replace the placeholder divs
3. Update the text content as needed
4. Update the pricing information (currently shows €xxx)
5. Host on any web server

## Image Placeholders

The design includes placeholder areas for:
- Hero section image (right side)
- About section image (left side)

To add images, replace the `.hero-image-placeholder` and `.about-image-placeholder` divs with actual `<img>` tags.

## Customization

### Colors
Edit the CSS custom properties in `:root` to change the color scheme:
- `--primary`: Main accent color (mauve/pink)
- `--background-dark`: Footer background color
- `--text`: Main text color

### Fonts
The site uses Google Fonts:
- Cormorant Garamond (headings)
- Open Sans (body text)

## Browser Support

Compatible with all modern browsers:
- Chrome
- Firefox
- Safari
- Edge
